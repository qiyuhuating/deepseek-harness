# Pi workbench

Build the checkout with Node 24 and the pnpm version in package.json (`pnpm install --frozen-lockfile`, then `pnpm run build`). Start the upstream Web profile with `pnpm start:pi`. The original workspace picker, composer, stop button and session history drive the Pi engine. The model provider and model ID selected in Harness must also exist in Pi's catalog. Use Pi's credential store and, for a custom route, its models.json under PI_CODING_AGENT_DIR. Harness account credentials are not copied to Pi.

The launcher sets DSH_PI_SESSION_DIR (default DSH_HOME/pi) and starts the source checkout's dsh web entry point. Give each running host a separate private data directory. Keep the Harness home and Pi directory together when backing up a stopped host. Harness stores the UI transcript and Pi stores the model conversation and tool results in per-session JSONL files. The text adapter supports workspace reads, job history and schedule management. File reads and schedule operations pass through the owning agent's Harness tool admission and execution pipeline.

- Ask for job history to use harness_job_history. The default page contains up to 50 summaries. Pass nextCursor to read older records; new insertions do not move that boundary. SQLite retains the last observed lifecycle state and filters by owner plus shared jobs. A process crash may leave the last observed state as running.
- Ask to schedule a workflow with a label, steps, five-field cron and IANA timezone. harness_axiom_schedule_create registers it on the current session with the Harness durable scheduler. Delivery goes through the normal inbox into Pi. Existing schedule list, view and edit tools manage the same records. The host must be running for on-time delivery.
- The launcher mirrors host stdout and stderr into runtime.log, rolling over in place at 8 MiB. Export the current log before rollover if needed. Pi JSONL conversations, job history and the Harness event store are separate data files outside this diagnostic quota. Protect the runtime log like the rest of the private host directory.
